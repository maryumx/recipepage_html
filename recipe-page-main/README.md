
# 🍽️ Recipe Page

A clean and modern **Recipe Page** built as part of a **Frontend Mentor** challenge. This project focuses on recreating the provided design using **HTML5** and **CSS3**, emphasizing semantic markup, clean styling, and attention to detail.

---

## 📌 Overview

This project was developed to practice translating a design into a functional webpage using only HTML and CSS. The primary goal was to recreate the layout as accurately as possible while maintaining clean, organized, and readable code.

---

## 🚀 Features

- Semantic HTML5 structure
- Modern CSS styling
- Clean and organized layout
- Well-structured typography
- Consistent spacing and alignment
- Pixel-accurate design implementation
- Beginner-friendly project structure
